# 쇼츠 만들기 — 터미널 열기부터 MP4 3개까지

방배동 예심교회 주일설교 → 유튜브 쇼츠 3편.
맥미니(M1) 기준. 만들고 싶을 때마다 이 문서대로만 하면 된다.

**플랜이 두 개 있다. 둘 중 하나만 고른다.**

| | 플랜 A — 알아서 | 플랜 B — 내가 지정 |
|---|---|---|
| 영상 고르기 | 채널에서 무작위로 뽑음 | 내가 유튜브 주소를 넣음 |
| 명령 | `bash scripts/shorts-auto.sh` | `bash scripts/shorts-url.sh "주소"` |
| 언제 | 아무거나 하나 만들고 싶을 때 | 이번 주 설교를 꼭 찍어서 만들 때 |

**전사 · 구간 선별 · 자막 · 엔드카드 · 렌더는 두 플랜이 완전히 똑같다.**

---

## 0단계 · 터미널 열기 (매번)

`command` + `스페이스` → `터미널` 입력 → `Enter`.

검은 창이 뜨고 이렇게 끝나는 줄이 보인다:

```
sunny-yeshim@cskui-Macmini ~ %
```

`%` 뒤에 명령을 친다. 아래 명령들은 **한 줄씩** 복사해서 붙여넣고 `Enter`.

> **`#` 뒤의 설명은 같이 복사하지 말 것.**
> 맥 기본 셸(zsh)은 `#` 을 주석으로 안 봐서 그대로 명령의 일부가 된다.
> 이 문서의 명령 줄에는 주석을 안 붙여 뒀다. 줄 전체를 복사해도 된다.

## 1단계 · 작업 폴더로 이동 (매번)

```bash
cd ~/shorts-factory
```

`%` 앞이 `shorts-factory` 로 바뀌면 성공이다.

## 2단계 · 최신 코드 받기 (매번, 5초)

```bash
git pull
```

`Already up to date.` 가 나와도 정상이다.

# 플랜 A · 알아서 골라서 만들기

## A-3단계 · 실행

```bash
bash scripts/shorts-auto.sh
```

**이게 끝이다.** 아직 안 만든 주일예배 중 하나를 무작위로 뽑아 렌더까지 간다.

### 만들기 전에 뭐가 남았는지 보고 싶으면

```bash
python3 scripts/sermon_shorts.py sermons
```

이미 만든 편은 숨겨서 보여준다. 목록만 읽는 거라 **돈이 안 든다.**

# 플랜 B · 내가 주소를 넣어서 만들기

## B-3단계 · 유튜브에서 주소 복사

1. 유튜브에서 `방배동 예심교회` 채널 → **실시간 스트림** 탭
   (주일예배는 "동영상" 탭이 아니라 여기 있다. 동영상 탭은 수요예배·새벽기도다.)
2. 만들 설교를 연다
3. 주소창의 주소를 복사한다 — `https://www.youtube.com/watch?v=...`

## B-4단계 · 실행

```bash
bash scripts/shorts-url.sh "https://www.youtube.com/watch?v=여기에붙여넣기"
```

**주소를 큰따옴표 `"` 로 감싼다.** 유튜브 주소의 `?` 와 `&` 는 따옴표가 없으면
셸이 먼저 먹어버린다.

폴더 이름은 **그 예배 날짜**로 자동으로 붙는다. 오늘 날짜가 아니다.

# 여기서부터는 두 플랜 공통

## 실행하면 이런 순서로 지나간다

```
━━ 대상 선정          (플랜 A만) 영상 고르기
━━ 1/4 원본 내려받기   yt-dlp        5~15분
━━ 2/4 한국어 전사     whisper       20~40분   ← 제일 오래 걸린다
━━ 3/4 구간 선별       전사본 읽고 3구간 고르기   2~5분
━━ 4/4 렌더           자막·크롭·엔드카드        3~10분
━━ 완료
```

**전체 40분~1시간.** 예배 실황이 100분인 편도 있어 길이에 따라 늘어난다.
2단계에서 몇 분간 아무 글자도 안 나올 수 있는데 정상이다. 멈춘 게 아니다.

전사 전에 유튜브 자동자막으로 설교 구간을 먼저 잡는다. 그래서 100분짜리라도
설교 35분만 전사한다 — 자동자막은 거칠어서 화면 자막으로는 안 쓰고 위치만 쓴다.

- 터미널 창은 **닫지 말 것.** 닫으면 중단된다.
- 맥이 잠들면 멈춘다. 시스템 설정 → 잠금 화면 → 디스플레이 끄기 `안 함` 으로
  두거나, 그냥 가끔 마우스를 움직인다.
- 중간에 끊겨도 같은 명령을 다시 치면 **끝난 단계는 건너뛰고 이어서** 간다.
  받아둔 영상을 다시 받지 않는다.

## 결과 확인

끝나면 마지막에 폴더 이름이 나온다. 예: `SUN-2026-08-09`.

```bash
open office/production/SUN-2026-08-09/renders
```

Finder가 열리고 MP4 3개가 있다. 더블클릭해서 본다.

제목·설명·주의사항은 같은 폴더 위쪽에 있다:

```bash
open office/production/SUN-2026-08-09/publish-package.md
```

여기에 각 클립의 **제목 / 훅 / 설명문 / 왜 이 구간인지** 가 정리돼 있다.
유튜브에 올릴 때 그대로 복사해 쓰면 된다.

## 업로드

**자동 업로드는 없다.** 마음에 드는 편을 골라 직접 올린다.
`publish-package.md` 에 `⚠️` 가 붙은 클립은 올리기 전에 꼭 확인한다 —
찬양이 깔렸거나(Content ID 위험) 회중석 얼굴이 잡힌 경우다.

### 인스타그램 릴스 썸네일이 검게 나올 때

핸드폰 앱으로 올리면 괜찮은데 **컴퓨터로 올리면** 커버 후보 중 하나가
가끔 검은 프레임으로 잘못 뽑힌다. 영상 파일은 멀쩡하다 — 인스타그램이
컴퓨터 업로드를 처리하는 방식의 문제다.

렌더할 때 `renders/` 안에 클립마다 `clip-01-cover.jpg` 같은 파일이 자동으로
같이 생긴다. 업로드 화면의 "커버 사진"에서:

1. 기본으로 골라진 후보가 검게 보이면 그대로 두지 않는다
2. **"컴퓨터에서 선택"** 을 눌러 같은 폴더의 `-cover.jpg` 파일을 직접 올린다
3. 이렇게 이미지 파일로 직접 올린 커버가, 영상 안에서 프레임을 긁어 고르는
   것보다 게시 후에도 훨씬 안정적으로 유지된다

방금 올렸는데 **프로필 화면(격자)에서만 잠깐 검게 보이는 건 다른 문제다** —
게시물을 직접 열어보면 정상인데 격자 썸네일만 그렇다면, 인스타그램이 격자용
썸네일을 몇 분 늦게 만드는 것뿐이다. 새로고침하면 곧 정상으로 바뀐다.

## 엔드카드 — 설교 영상을 찾아올 수 있게

**쇼츠 본편이 끝나면 4초짜리 카드가 붙는다.** 다섯 가지가 들어간다.

```
        2024년 6월 23일 주일예배      ← 언제 드린 예배인지
           신명기 12:1-8            ← 설교 본문
     택하신 곳으로 나아가야 하는 이유    ← 설교 제목
         설교 · 장선기 목사           ← 설교자
          방배동 예심교회             ← 교회명
       youtube.com/@yeshim1126
```

쇼츠는 채널을 떠나 혼자 돌아다닌다. 이 카드가 없으면 그냥 낯선 사람이
말하는 토막이 된다. **본문과 제목은 정확하고 유일해서**, 이걸 보고 유튜브에
검색하면 원래 설교 영상이 바로 나온다.

카드는 **저절로 만들어진다.** 유튜브 영상 제목에 날짜·본문·제목·설교자가
전부 들어 있어서 거기서 뽑는다. 채널이 써 온 두 가지 제목 형식을 다 읽는다:

```
2026-08-09 [삼하 19:31-39] 나이 들면 바르실래처럼 / 장선기 목사
2024.06.23 택하신 곳으로 나아가야 하는 이유 신명기 12:1-8 장선기목사
```

- 본문은 **풀어서** 쓴다 — `삼하` → `사무엘하`. 그래야 검색된다.
- 날짜는 제목이 아니라 **폴더 이름**에서 가져온다. 채널 제목의 날짜가 틀린
  적이 있어서다(2026-07-14는 화요일, 실제로는 07-12 주일예배였다).

### 내용을 고치고 싶으면

`end-card.json` 을 고치고 렌더만 다시 돌린다. 파일이 이미 있으면 다시
만들지 않으므로, 고친 내용이 그대로 유지된다.

```bash
open -e office/production/SUN-2026-08-09/end-card.json
```
```bash
python3 scripts/sermon_shorts.py render SUN-2026-08-09
```

### 카드를 빼고 싶으면

```bash
python3 scripts/sermon_shorts.py render SUN-2026-08-09 --no-end-card
```

## 마음에 안 들 때

### 구간을 바꾸고 싶다

`clips.json` 의 `start` / `end` 초만 고치고 렌더만 다시 돌린다.
전부 다시 할 필요 없다.

```bash
open -e office/production/SUN-2026-08-09/clips.json
```
```bash
python3 scripts/sermon_shorts.py render SUN-2026-08-09
```

### 3편 말고 다른 구간으로 다시 골라달라

```bash
python3 scripts/sermon_shorts.py select SUN-2026-08-09 --count 3
```
```bash
python3 scripts/sermon_shorts.py render SUN-2026-08-09
```

### 설교 구간을 잘못 잡았다

설교가 시작·끝나는 시각을 직접 넘긴다. 전사부터 다시 하므로 시간이 걸린다.

```bash
rm office/production/SUN-2026-08-09/transcript.json
```
```bash
python3 scripts/sermon_shorts.py transcribe SUN-2026-08-09 --sermon-window 0:45:00 1:20:00
```

### 아예 다른 설교로 (플랜 A)

`shorts-auto.sh` 를 다시 치면 다른 편이 나온다. 무작위이므로.

## 처음 한 번만 — 설치

이미 해 뒀다면 건너뛴다. 확인만 하려면:

```bash
python3 scripts/sermon_shorts.py doctor
```

`ffmpeg` `yt-dlp` `whisper-cli` `korean font` `whisper model` 이 전부 `OK` 면
준비된 것이다. `GEMINI_API_KEY` 가 `n/a` 로 나오는 건 **정상이다** —
whisper가 있으면 안 쓴다.

`MISS` 가 있으면:

```bash
bash scripts/setup_render_env.sh --with-whisper
```

설치가 끝나면 마지막에 `export` 로 시작하는 두 줄이 나온다. 그 두 줄을
`~/.zshrc` 에 넣고 터미널을 새로 열어야 `whisper-cli` 가 잡힌다:

```bash
open -e ~/.zshrc
```

렌더 계층 전체가 제대로 도는지 확인 (인터넷 없이 30초, 무료):

```bash
bash scripts/smoke_test_render.sh
```

`PASS` 가 나오면 된 것이다.

## 막힐 때

| 화면에 나온 것 | 뜻 | 할 것 |
|---|---|---|
| `URL이 아니다: '#'` | 주석까지 복사됨 | 명령 줄만 복사한다 |
| `인자를 받지 않는다` | 위와 같음 | 명령만 친다 |
| `GEMINI_API_KEY not set` | 옛날 코드 | `git pull` 하고 다시 |
| `전사할 수단이 없다` | whisper 설치 안 됨 | 위 "처음 한 번만" |
| `엔드카드: 원본 제목을 못 찾아` | 제목 정보가 없음 | `end-card.json` 을 직접 만든다 |
| `no such file or directory` | 폴더가 아님 | `cd ~/shorts-factory` |
| `command not found: git` | 개발자 도구 없음 | `xcode-select --install` |
| 20분간 아무 것도 안 나옴 | 전사 중 | 정상. 기다린다 |
| 릴스 썸네일이 검게 나옴 | 컴퓨터 업로드 버그 | `-cover.jpg` 를 "컴퓨터에서 선택"으로 직접 올린다 |

그래도 안 되면 **터미널에 나온 글자를 그대로 복사해서** Claude에게 붙여넣는다.
