# 이재용 목사님 맥에 설치하기 — 양재 드림의 교회 쇼츠 자동화

새 맥에 **아무것도 안 깔려 있다고 생각하고** 처음부터 끝까지 적었다. 클로드 코드도,
Homebrew도, 깃(git)도 전부 이 문서 안에서 깐다.

전부 무료다. API 키가 하나도 필요 없다 (한국어 인식은 인터넷 없이 도는 whisper를 쓴다).

| | 무엇을 | 누가 | 언제 |
|---|---|---|---|
| **0부** | 코드를 깃허브에 올리기 | **장선기 목사님**, 본인 맥미니에서 | 딱 한 번 |
| **1부** | 이재용 목사님 새 맥에 설치 | **이재용 목사님**, 새 맥에서 | 딱 한 번 |
| **2부** | 쇼츠 만들기 | 이재용 목사님 | 만들 때마다 |
| **3부** | 자막·화면 고치기 | 이재용 목사님 | 마음에 안 들 때 |

- 맥 (인텔 / M1 / M2 / M3 다 됨)
- 여유 공간 **20GB** — 전사 모델 3GB, 예배 영상 한 편 1GB 정도
- 인터넷

# 0부 · 코드를 깃허브에 올리기 (장선기 목사님, 딱 한 번)

지금 만든 `yj-shorts-factory` 는 이 맥미니 안에만 있고 깃허브에는 없다.
이재용 목사님 맥이 이 코드를 받아 가려면 먼저 어딘가에 올려 둬야 한다.
**이 0부만 장선기 목사님이 맥미니 터미널에서 직접 한다.** (Cowork는 이 맥미니의
진짜 터미널에 직접 접속할 수 없어서, 이 한 단계만은 대신 실행해 드릴 수 없다.)

## 0-1. 깃허브에 빈 저장소 만들기

브라우저로 <https://github.com/new> 를 연다.

- **Repository name**: `yj-shorts-factory`
- **Public** 선택 (기존 `shorts-factory` 도 Public이라 그대로 맞춘다)
- **Add a README file** 체크박스는 **끈다** — 이미 있는 코드를 올릴 것이므로 비워
  둬야 충돌이 안 난다
- **Create repository** 클릭

## 0-2. 맥미니 터미널에서 올리기

터미널을 열고 한 줄씩 붙여넣는다.

```bash
cd ~/yj-shorts-factory
```

```bash
git remote add origin https://github.com/sunki2024-star/yj-shorts-factory.git
```

> 깃허브 아이디가 `sunki2024-star` 가 아니면 그 부분만 본인 아이디로 바꾼다.

```bash
git branch -M main
```

```bash
git push -u origin main
```

깃허브 로그인 창이 뜨면 로그인한다 (브라우저로 뜨는 경우가 많다).

확인:

```bash
git remote -v
```

`origin  https://github.com/…/yj-shorts-factory.git (push)` 가 보이면 끝이다.
브라우저에서 `https://github.com/sunki2024-star/yj-shorts-factory` 를 열어
파일들이 올라와 있는지 봐도 된다.

> **나중에 이 파이프라인을 또 고치면** (자막 색, 화면 배치 등), 같은 폴더에서
> `git add -A && git commit -m "…" && git push` 로 한 번 더 올리면 된다.
> 이재용 목사님 쪽은 2부 맨 앞의 `git pull` 한 줄로 그 수정을 받는다.

# 1부 · 이재용 목사님 새 맥에서 설치 (딱 한 번, 40분~1시간)

## 1. 터미널 열기

`command` + `스페이스` → `터미널` → `Enter`.

검은 창이 뜨고 `%` 로 끝나는 줄이 보인다. 여기에 명령을 친다.
아래 명령들은 **한 줄씩** 복사해 붙여넣고 `Enter`.

> 회색 상자 안의 것만 복사한다. 설명 문장은 같이 복사하지 않는다.

## 2. 개발자 도구

```bash
xcode-select --install
```

창이 뜨면 **설치**를 누른다. 5~10분. 이미 깔려 있으면
`command line tools are already installed` 라고 나오는데 정상이다.

## 3. Homebrew

맥에 프로그램을 깔아 주는 도구다.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

맥 로그인 암호를 물으면 친다. **화면에 아무 글자도 안 나오는 게 정상이다.**
다 치고 `Enter`. 중간에 한 번 더 `Enter` 를 누르라고 할 수 있다.

끝나면 화면 마지막에 `eval "$(/opt/homebrew/bin/brew shellenv)"` 같은 줄이
나온다. **그 줄을 그대로 복사해서 한 번 더 실행한다.** 그리고 다음 줄로
앞으로도 자동으로 잡히게 등록해 둔다:

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
```

확인:

```bash
brew --version
```

버전이 나오면 됐다.

## 4. Node.js와 Claude Code

```bash
brew install node
```

```bash
npm install -g @anthropic-ai/claude-code
```

```bash
claude
```

처음 실행하면 브라우저가 열리고 로그인하라고 한다. **이재용 목사님의 Claude
계정**으로 로그인한다. 로그인이 끝나면 `/exit` 를 쳐서 나온다.

> **Claude 구독이 있으면 추가 비용이 없다.** 쇼츠 구간을 고르는 데만 쓴다.

## 5. 코드 받기

```bash
cd ~
```

```bash
git clone https://github.com/sunki2024-star/yj-shorts-factory
```

```bash
cd ~/yj-shorts-factory
```

## 6. 교회 설정 파일 만들기

**이 단계를 빼먹으면 예심교회 것으로 렌더된다.** 교회마다 다른 값(채널·재생목록)은
보안상 깃허브에 올리지 않으므로, 새 맥에서는 이 파일을 직접 한 번 만들어야 한다.
아래를 통째로 복사해 붙여넣고 `Enter`:

```bash
cat > church.json << 'EOF'
{
  "channel": "https://www.youtube.com/@양재드림의교회",
  "church": "양재 드림의 교회",
  "playlist_sunday": "https://www.youtube.com/playlist?list=PLDAU49xS8DLYtyTEVXWg9Yw7NbbV2guDu",
  "playlist_wed": "https://www.youtube.com/playlist?list=PLDAU49xS8DLbxhiVb0SOR2VKky5Hpn4hI"
}
EOF
```

확인:

```bash
cat church.json
```

방금 넣은 내용이 그대로 보이면 됐다. (설교자 이름은 넣지 않는다 — 이 채널은
영상 제목에 설교자 이름이 없어서, 엔드카드·설명문에는 "이재용 목사"가 코드에
이미 고정값으로 들어가 있다.)

## 7. 도구 설치

```bash
bash scripts/setup_render_env.sh --with-whisper
```

**20~40분 걸린다.** 영상 편집기(ffmpeg), 유튜브 다운로더(yt-dlp), 한국어 음성
인식 모델(3GB)을 받는다. 중간에 여러 줄이 지나가는데 그냥 두면 된다.

끝나면 마지막에 `export` 로 시작하는 **두 줄**이 나온다. 그 두 줄을 넣는다:

```bash
echo 'export PATH="$HOME/whisper.cpp/build/bin:$PATH"' >> ~/.zshrc
```

```bash
echo 'export WHISPER_MODEL="$HOME/whisper.cpp/models/ggml-large-v3.bin"' >> ~/.zshrc
```

**터미널을 완전히 닫고 새로 연다.** (`command` + `Q` → 다시 열기)

### 7-1. 자막이 되는 ffmpeg인지 확인 (2분)

**이 확인을 건너뛰면 렌더 단계에서 막힌다.** Homebrew의 기본 `ffmpeg` 는
자막을 입히는 부품(libass)을 **빼고** 오는 경우가 있다.

```bash
ffmpeg -filters | grep subtitles
```

`subtitles` 가 들어간 줄이 **하나라도 나오면 통과다.**

아무것도 안 나오면:

```bash
brew install ffmpeg-full
```

15~20분. 끝나면 다시:

```bash
ffmpeg -filters | grep subtitles
```

그래도 안 나오면:

```bash
brew link --overwrite ffmpeg-full
```

> **`brew reinstall ffmpeg` 는 소용없다.** `-full` 이 붙은 쪽을 깔아야 한다.

## 8. 확인

```bash
cd ~/yj-shorts-factory
```

```bash
bash scripts/shorts doctor
```

이렇게 나와야 한다:

```
  OK    ffmpeg       /opt/homebrew/bin/ffmpeg
  OK    yt-dlp       /opt/homebrew/bin/yt-dlp
  OK    whisper      /Users/…/whisper.cpp/build/bin/whisper-cli
  OK    subtitles    자막을 입힐 수 있다 (libass)
  OK    claude       /opt/homebrew/bin/claude
  OK    korean font  2 file(s) in …/assets/fonts
  OK    whisper model /Users/…/ggml-large-v3.bin
  n/a   GEMINI_API_KEY not needed — whisper handles transcription
```

`subtitles` 가 `MISS` 면 7-1번으로 돌아간다. `GEMINI_API_KEY` 가 `n/a` 인 것은
정상이다 — whisper가 있으면 안 쓴다.

재생목록이 제대로 잡혔는지 본다:

```bash
bash scripts/shorts sermons
```

주일예배·수요기도회 목록이 쭉 나오면 됐다. **아무것도 안 나오면** 6번의
`church.json` 을 다시 확인한다.

마지막으로 실제 렌더가 되는지 본다. 인터넷 없이 30초, 무료:

```bash
bash scripts/smoke_test_render.sh
```

`PASS` 가 나오면 설치 끝이다.

# 2부 · 쇼츠 만들기 (만들 때마다)

## 매번 하는 두 줄

```bash
cd ~/yj-shorts-factory
```

```bash
git pull
```

`git pull` 은 장선기 목사님이 나중에 화면·자막을 더 고쳐서 올리면 그걸
받아 오는 줄이다. 빼먹어도 당장은 돌아가지만, 가끔 한 번씩은 받아 두는 게 좋다.

## 플랜은 둘, 하나만 고른다

| | 플랜 A — 알아서 (주일예배) | 플랜 B — 내가 지정 |
|---|---|---|
| 영상 | 주일예배 재생목록에서 무작위로 뽑음 | 주소를 직접 넣음 (수요기도회 포함) |

### 플랜 A — 주일예배

```bash
bash scripts/shorts-auto.sh
```

아직 안 만든 주일예배 중 하나를 뽑아 렌더까지 간다. 끝.

### 플랜 B — 수요기도회 등, 내가 고른 영상

유튜브에서 원하는 예배 영상을 열고 주소를 복사한다.

```bash
bash scripts/shorts-url.sh "https://www.youtube.com/watch?v=여기에붙여넣기"
```

주소를 **큰따옴표로 감싼다.**

## 렌더 전에 화면 확인 · 1분

세로 화면은 가로 영상의 일부만 쓴다. 설교자가 그 안에 들어왔는지 **굽기 전에**
사진으로 본다.

```bash
bash scripts/shorts preview 폴더이름
```

(`폴더이름` 은 위에서 만들어진 것, 예: `SUN-2026-09-06`)

Finder가 열리면 사진을 본다. 이상하면 3부 **"화면이 이상하게 잘렸을 때"** 로 간다.

## 기다리기

```
1/4 원본 내려받기   5~15분
2/4 한국어 전사     20~40분   ← 제일 오래 걸린다
3/4 구간 선별       2~5분
4/4 렌더           3~10분
```

- 터미널 창을 **닫지 말 것.** 닫으면 중단된다.
- 맥이 잠들면 멈춘다. 시스템 설정 → 잠금 화면 → 디스플레이 끄기를 `안 함` 으로
- 중간에 끊겨도 **같은 명령을 다시 치면 이어서** 간다.

## 결과 보기

렌더가 끝나면 **Finder가 저절로 열린다.**

```
폴더이름/
├── renders/            ← MP4 3편. 여기서 확인한다
├── captions/           ← 자막이 틀리면 여기를 고친다
├── publish-package.md  ← 제목 · 설명문 · 선정 근거
└── source/             ← 받아둔 원본 (지워도 된다)
```

`publish-package.md` 에 제목 · 훅 · 설명문이 정리돼 있다. 유튜브에 올릴 때
그대로 복사해 쓰면 된다.

## 업로드

**자동 업로드는 없다.** 마음에 드는 편을 골라 직접 올린다.

# 3부 · 고치기

## 이 쇼츠의 화면 구성 — 참고

- 위쪽 검은 여백에 **노란색** 제목(훅 문구)
- 가운데 박스 안에 실제 설교 영상 (원본 그대로의 비율)
- 아래쪽 검은 여백에 **흰색** 자막, 그 아래 교회 로고 (영상 내내 고정)
- 별도의 엔드카드 화면은 없다 — 로고가 영상 내내 보이기 때문

## 자막 글자가 틀렸을 때

**한 단어가 계속 틀리는 경우:**

```bash
bash scripts/shorts fix 폴더이름 잘못된단어 맞는단어 --remember
```

```bash
bash scripts/shorts render 폴더이름
```

`--remember` 를 붙이면 앞으로 만드는 모든 편에 자동으로 적용된다.

**문장을 직접 다듬고 싶은 경우:**

렌더가 끝나면 `captions` 폴더가 저절로 만들어져 있다.

```bash
open -e office/production/폴더이름/captions/clip-01.srt
```

텍스트편집기에서 **맨 아랫줄 글자만** 고치고 `command` + `S` 로 저장한다.
시간(숫자와 `-->`) 줄은 건드리지 않는다.

```bash
bash scripts/shorts render 폴더이름
```

한 편만 다시 만들려면:

```bash
bash scripts/shorts render 폴더이름 --only clip-02
```

## 화면이 이상하게 잘렸을 때

```bash
bash scripts/shorts preview 폴더이름
```

으로 지금 어디를 잡고 있는지 먼저 본다. 그래도 어긋났으면
`office/production/폴더이름/clips.json` 을 연다:

```bash
open -e office/production/폴더이름/clips.json
```

각 클립의 `"crop"` 값을 조정한다. 숫자는 원본 영상 기준 픽셀이다.

```
"crop": { "x": 670, "y": 10, "h": 1070 }

   x  왼쪽에서 몇 픽셀부터
   y  위에서 몇 픽셀부터
   h  높이
```

고친 뒤:

```bash
bash scripts/shorts render 폴더이름
```

## 제목 크기

화면 위쪽 노란 제목은 기본 **92** 다. 한 번만 크게 하려면:

```bash
TITLE_SIZE=110 bash scripts/shorts render 폴더이름
```

늘 크게 하고 싶으면:

```bash
echo 'export TITLE_SIZE=110' >> ~/.zshrc
```

## 용량이 찰 때 — 원본만 지운다

```bash
rm -rf office/production/폴더이름/source
```

완성된 MP4(`renders/`)와 자막은 그대로 남는다. 원본은 필요하면 다시 받아진다.

# 막힐 때

| 화면에 나온 것 | 뜻 | 할 것 |
|---|---|---|
| `command not found: brew` | Homebrew 경로 미등록 | 3번 `echo …zprofile` 다시, 터미널 새로 열기 |
| `command not found: git` | 개발자 도구 없음 | `xcode-select --install` |
| `Repository not found` (git clone) | 0부가 아직 안 됐음 | 장선기 목사님께 0부 완료 여부 확인 |
| `아무것도 못 찾았다` | church.json이 없거나 잘못됨 | 6번으로 돌아가 다시 만들기 |
| `No such filter: 'subtitles'` | 자막 부품 없는 ffmpeg | `brew install ffmpeg-full` — 7-1번 |
| `자막을 고쳤는데 그대로` | 저장 안 됨 | `command + S` 후 다시 렌더 |
| `URL이 아니다: '#'` | 설명 문장까지 복사됨 | 회색 상자 안만 복사 |
| 20~40분간 아무것도 안 나옴 | 한국어 전사 중 | 정상. 기다린다 |
| `No space left` | 디스크 부족 | 오래된 `source/` 지우기 |

그래도 안 되면 **터미널 글자를 그대로 복사해서** Claude에게 붙여넣는다.
