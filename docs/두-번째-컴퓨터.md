# 0부 · 아이맥 기본 도구 (한 번만, 20~30분)

## 0-1. 터미널 열기

`command` + `스페이스` 를 누르고 **터미널** 이라고 친 뒤 `Enter`. 검은 창이
뜨고 `%` 로 끝나는 줄이 보인다.

> 회색 상자 안의 것만 복사한다. 설명 문장은 같이 복사하지 않는다.
> 한 줄씩 붙여넣고 `Enter`.

## 0-2. 개발자 도구 (5~10분)

```bash
xcode-select --install
```

창이 뜨면 **설치**를 누른다. 이미 깔려 있으면
`command line tools are already installed` 라고 나오는데 그것도 정상이다.

```bash
git --version
```

## 0-3. Homebrew (10~20분)

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

맥 로그인 암호를 물으면 친다. **화면에 아무 글자도 안 나오는 것이 정상이다.**

끝나면 **다음 두 줄을 반드시 실행한다.**

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
```

```bash
eval "$(/opt/homebrew/bin/brew shellenv)"
```

```bash
brew --version
```

## 0-4. Node.js (3~5분)

```bash
brew install node
```

```bash
node --version
```

두 줄 다 `sunki2024-star` 여야 한다.

## 2-1. 이 컴퓨터에서도 밀 수 있게

나중에 이 아이맥에서 고친 것을 올리려면 GitHub 토큰이 필요하다. 지금 해 두면
편하다. 주소에 아이디를 박아 둔다:

```bash
git remote set-url origin https://sunki2024-star@github.com/sunki2024-star/shorts-factory
```

토큰은 <https://github.com/settings/tokens> → **Generate new token (classic)**
→ Note 는 아무 이름(`shorts-factory 아이맥`) → **`repo` 만 체크** →
Generate token. 나오는 `ghp_...` 를 복사해 둔다. **그 화면을 벗어나면 다시 못
본다.**

`git push` 가 처음 물을 때 붙여넣으면 맥이 기억한다.

- Username — `sunki2024-star`
- Password — 그 토큰 (맥 로그인 암호가 아니다)

> 붙여넣어도 **화면에 아무 글자도 안 나오는 것이 정상이다.** 그대로 `Enter`.

# 3부 · 도구 설치 (20~40분)

```bash
bash scripts/setup_render_env.sh --with-whisper
```

ffmpeg · yt-dlp · 한국어 폰트 · 음성 인식 모델(3GB)을 받는다. 끝나면
`export` 로 시작하는 두 줄이 나온다. 넣는다:

```bash
echo 'export PATH="$HOME/whisper.cpp/build/bin:$PATH"' >> ~/.zshrc
```

```bash
echo 'export WHISPER_MODEL="$HOME/whisper.cpp/models/ggml-large-v3.bin"' >> ~/.zshrc
```

**터미널을 완전히 닫고 새로 연다** (`command` + `Q` → 다시 열기).

## 3-1. 자막이 되는 ffmpeg인지 확인 (2분) — 건너뛰지 말 것

```bash
ffmpeg -filters | grep subtitles
```

`subtitles` 가 든 줄이 **하나라도 나오면 통과다.** 아무것도 안 나오면:

```bash
brew install ffmpeg-full
```

```bash
ffmpeg -filters | grep subtitles
```

그래도 안 나오면:

```bash
brew link --overwrite ffmpeg-full
```

> **`brew reinstall ffmpeg` 는 소용없다.** Homebrew의 기본 ffmpeg 는 자막
> 부품(libass)을 빼고 온다. `-full` 이 붙은 쪽을 깔아야 한다.

**판단은 전부 저장소에 글로 남아 있다.**

```bash
cd ~/shorts-factory
```

```bash
claude
```

클로드가 뜨면 아래를 그대로 붙여넣는다.

```
docs/session-handoff.md 읽고 지금 상태 요약해 줘. 그다음 이번 주 설교로 쇼츠 만들자.
```

**제대로 이어받았는지 보는 법** — 요약에 이런 것들이 들어 있어야 한다.

- 맥에서 무료로 돌아간다는 것 (yt-dlp + whisper, API 키 없음)
- 설교자를 **찾아서** 가운데 놓는다는 것 (고정 좌표가 아니라)
- `captions/` 가 전사본보다 우선한다는 것
- **업로드는 사람이 한다**는 것

이게 안 나오면 문서를 안 읽은 것이다. 다시 시킨다:

```
docs/session-handoff.md 를 먼저 읽어라. 그 안에 왜 그렇게 만들었는지가 있다.
```

더 자세한 규칙까지 물려주려면:

```
CLAUDE.md 와 .claude/context/youtube-channel.md 도 읽어라.
```

# 6부 · 두 대를 오가며 쓰기

같은 저장소를 두 컴퓨터가 본다. 규칙은 이제 한 줄이다.

**시작할 때 — 받는다.**

```bash
cd ~/shorts-factory
```

```bash
git pull
```

**쇼츠를 만든 뒤는 — 이제 손 갈 게 없다.** `bash scripts/shorts render …` 가
끝나면 `office/produced/`(어떤 설교를 이미 만들었는지, 설교 하나당 파일 하나로 적힌
곳)에 새로 생긴 파일을 자동으로 커밋하고 올린다. 화면에 이게 뜨면 성공이다.

```
==> 제작 기록을 GitHub에 올렸다 — 다른 컴퓨터도 이 설교는 건너뛴다
```

인터넷이 없거나 다른 이유로 못 올렸으면 이렇게 뜬다 — 렌더 자체는 그대로
끝난 상태이니 급할 것 없다.

```
    (제작 기록을 못 올렸다 — 나중에 git push 를 직접 한 번 해 준다)
```

이때는 나중에 손으로 세 줄이면 된다.

```bash
git add office/produced
```

```bash
git commit -m "SUN-2026-09-06 만듦"
```

```bash
git push
```

이걸 안 올려 두면 다른 컴퓨터가 같은 설교를 다시 뽑는다.

## 무엇이 오가고 무엇이 안 오가나

| | 두 컴퓨터가 공유하나 |
|---|---|
| 프로그램 · 문서 · 설정 | **그렇다** — `git pull` 로 |
| 만든 기록 (`office/produced/`) | **그렇다** — 올려 두면 |
| 자막 사전 (`fix … --remember`) | **그렇다** — 올려 두면 |
| 완성된 MP4 (`renders/`) | **아니다** — 용량이 커서 안 올린다 |
| 받아둔 원본 (`source/`) | **아니다** — 같은 주소로 다시 받으면 된다 |

MP4는 만든 컴퓨터에만 있다. 집에서 만든 영상을 교회에서 올리시려면 그 파일만
따로 옮기시면 된다 (에어드롭·USB·클라우드 드라이브 무엇이든).

# 막힐 때

| 화면에 나온 것 | 뜻 | 할 것 |
|---|---|---|
| `command not found: brew` | Homebrew 경로 미등록 | 0-3의 `echo …zprofile` 두 줄, 터미널 새로 열기 |
| `No such filter: 'subtitles'` | 자막 부품 없는 ffmpeg | `brew install ffmpeg-full` — 3-1 |
| `permission denied` (push) | 다른 계정으로 로그인돼 있음 | 아래 참조 |
| `Invalid username or token` | 토큰이 틀렸거나 `repo` 미체크 | 토큰 새로 만들기 |
| `/login` 후에도 다른 계정 | 브라우저에 그 계정이 남아 있음 | claude.ai 로그아웃 후 다시 |
| `전사할 수단이 없다` | whisper 미설치 | `setup_render_env.sh --with-whisper` |
| 20분간 아무것도 안 나옴 | 전사 중 | 정상. 기다린다 |

**push 가 `permission denied` 일 때** — 맥에 다른 GitHub 계정이 저장돼 있는
것이다. 지우고 다시 한다:

```bash
printf 'protocol=https\nhost=github.com\n\n' | git credential-osxkeychain erase
```

```bash
git push -u origin claude/shorts-creation-automation-0xaii8
```

그래도 안 되면 **터미널에 나온 글자를 그대로 복사해서** 클로드에게 붙여넣는다.
어디서 멈췄는지가 그 안에 다 있다.
