# 인쇄용 PDF

세 안내서의 A4 인쇄본. 화면용 페이지와 같은 내용이고, 종이에 맞게만 다르다:

- 복사 버튼은 빠지고, 터미널 상자는 흰 종이에 맞게 밝게
- 긴 명령은 잘리지 않고 접힘 (화면에서는 옆으로 스크롤된다)
- 부(1부·2부·3부)마다 새 페이지에서 시작
- 링크는 주소가 괄호로 함께 인쇄됨
- 쪽 번호와 문서 이름이 아래쪽에

| 파일 | 대상 | 쪽수 |
|---|---|---|
| `쇼츠-만들기-맥.pdf` | 예심교회 · macOS | 17 |
| `쇼츠-만들기-윈도우.pdf` | 예심교회 · Windows | 18 |
| `우리교회-쇼츠-만들기.pdf` | 다른 교회 · 맥·윈도우 공통 | 15 |

## 다시 만들려면

내용을 고친 뒤 다시 뽑는 방법. Chromium으로 인쇄하는 것이라
화면에서 보는 것과 같은 레이아웃이 나온다.

```bash
pip install playwright pypdfium2
python3 scripts/make_guide_pdf.py
```
