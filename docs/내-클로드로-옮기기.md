# 아들 클로드에서 내 클로드로 옮기기

지금까지 이 파이프라인은 **아들 계정의 Claude**(클라우드 세션)에서 만들어졌다.
이제부터 **내 계정의 Claude**로, 내 맥에서 돌리려면 무엇을 해야 하는지.

> 명령어를 눌러 복사하면서 따라가는 웹 안내서:
> <https://claude.ai/code/artifact/2bf86765-2a3a-425e-815d-81dfb0045444>

## 먼저 — 옮길 게 생각보다 적다

| 무엇 | 지금 어디에 | 옮겨야 하나 |
|---|---|---|
| **프로그램(코드·문서·설정)** | 이미 내 맥 `~/shorts-factory` 안에 있다 | **아니다.** 그대로 쓴다 |
| **만든 기록**(어떤 설교를 이미 만들었는지) | 같은 폴더 `office/produced.json` | **아니다.** 같이 있다 |
| **Claude 계정** | 아들 계정으로 로그인돼 있다 | **그렇다.** 1번 |
| **GitHub 저장소** | `Kairose-master/shorts-factory` | 주인이 내가 아니면 2번 |
| **API 키**(Apify · Gemini) | 아들 세션 소유 | **필요 없다.** 3번 |

맥에서 돌리는 경로는 키가 하나도 필요 없다 — yt-dlp로 받고 whisper.cpp로 전사한다.
아들 계정의 유료 키는 클라우드 컨테이너의 제약 때문에 썼던 것이고, 내 맥에서는
쓰지 않는다. 이유는 `docs/porting-to-your-claude.md` 맨 위 표에 있다.

---

## 1. Claude Code를 내 계정으로 바꾼다

내 계정에도 **Claude 구독(Pro 또는 Max)** 이 있어야 한다. 구독이 있어야
구간 선별을 추가 비용 없이 돌린다.

터미널을 열고:

```bash
cd ~/shorts-factory
```

```bash
claude
```

Claude가 뜨면 그 안에서 차례로 친다. 명령 앞에 **슬래시(/)** 가 붙는다.

```
/logout
```

```
/login
```

브라우저가 열리면 **내 계정**(아들 계정 말고)으로 로그인한다. 돌아와서 확인:

```
/status
```

내 이메일이 보이면 된 것이다. `/exit` 로 나온다.

> 아들 계정으로 만들던 **클라우드 세션은 끝나도 된다.** 내 맥의 폴더는 그
> 세션과 아무 상관이 없다. 이미 다 내려받아져 있다.

---

## 2. GitHub 저장소를 내 것으로 (주인이 내가 아니면)

지금 이 폴더는 `Kairose-master/shorts-factory` 를 바라보고 있다. 확인:

```bash
git remote -v
```

주소에 **내 GitHub 아이디**가 있으면 이 절은 건너뛴다.

### 2-1. 웹에서 Fork

브라우저로 <https://github.com/Kairose-master/shorts-factory> 에 들어가
오른쪽 위 **Fork** 를 누른다. 내 계정 밑에 같은 저장소가 생긴다.

### 2-2. 맥이 내 저장소를 보게 한다

```bash
cd ~/shorts-factory
```

```bash
git remote set-url origin https://github.com/내아이디/shorts-factory
```

```bash
git remote -v
```

두 줄 다 내 아이디로 바뀌었으면 된다.

### 2-3. 지금까지의 작업을 내 저장소로 올린다

```bash
git push -u origin claude/shorts-creation-automation-0xaii8
```

GitHub 아이디와 **비밀번호 대신 토큰**을 물어본다. 토큰은
<https://github.com/settings/tokens> → **Generate new token (classic)** →
`repo` 항목만 체크 → 만든 뒤 나오는 긴 글자를 복사해 붙여넣는다.
**그 화면을 벗어나면 다시 못 본다.** 어딘가에 적어 둔다.

> 한 번 넣으면 맥이 기억한다. 다음부터는 안 묻는다.

이 다음부터 문서에 나오는 `git pull` 은 **내 저장소에서** 받아온다.

## 3. 키는 안 만든다

내 맥에서 돌리는 한 `GEMINI_API_KEY` 도 `APIFY_TOKEN` 도 필요 없다.
`.env` 파일을 만들 일도 없다.

**아들 계정에 남아 있는 키는 폐기하는 편이 안전하다.** 안 쓰는 키를 살려두면
누가 쓰든 요금이 나간다.

- Apify: <https://console.apify.com> → Settings → Integrations → 토큰 삭제
- Gemini: <https://aistudio.google.com/apikey> → 키 삭제

## 4. 제대로 넘어왔는지 확인

```bash
cd ~/shorts-factory
```

```bash
bash scripts/shorts doctor
```

왼쪽이 전부 `OK` 여야 한다. `MISS` 가 하나라도 있으면:

```bash
bash scripts/setup_render_env.sh --with-whisper
```

렌더 계층이 멀쩡한지 (네트워크 없이 30초):

```bash
bash scripts/smoke_test_render.sh
```

마지막 줄이 **PASS** 면 된다.

무엇이 남았는지 (돈 안 든다, 목록만 읽는다):

```bash
bash scripts/shorts sermons
```

한 편 만들어 본다:

```bash
bash scripts/shorts-auto.sh
```

여기까지 되면 옮긴 것이다. 이후 사용법은 `docs/설치-맥.md` 2부부터와 같다.

## 5. 내 Claude에게 처음 할 말

내 계정으로 로그인한 Claude를 `~/shorts-factory` 에서 열고 아래를 붙여넣는다.
이걸 읽으면 지금까지의 판단을 그대로 이어받는다.

````text
방배동 예심교회(@yeshim1126) 주일설교를 쇼츠로 만드는 파이프라인을 이어받았다.
이 폴더가 그 저장소다. 아들 계정에서 만들어 넘겨받은 것이고, 앞으로는 이 맥에서
내 계정으로 돌린다.

먼저 읽어라. 이미 내려진 판단이 들어 있으니 뒤집을 이유가 없으면 따른다:
  CLAUDE.md                           ← 전체 구조
  .claude/context/youtube-channel.md  ← 채널 구조와 제작 규칙
  docs/설치-맥.md                      ← 사람이 쓰는 순서

환경: 내 맥. 키 없음. yt-dlp + whisper.cpp large-v3 로 전부 무료로 돈다.

지켜야 할 것:
- 업로드는 절대 자동으로 하지 않는다. 렌더까지만 하고 내 승인을 받는다.
- 설교 구간을 먼저 잡고 그 안에서만 자른다. 찬양 구간은 Content ID에 걸린다.
- 회중석에 성도 얼굴이 잡힌 프레임은 크롭하거나 문제 구간으로 보고한다.
- 목사님 음성 합성/클로닝은 하지 않는다. 실제 하신 말씀만 자른다.
- 구간 선별은 전사본을 직접 읽고 판단하고, 왜 그 구간인지 근거를 붙인다.
- 유료 API를 쓰기 전에 대략 얼마가 나갈지 먼저 말한다.
````

## 옮김 체크리스트

- [ ] 내 계정에 Claude 구독이 있다
- [ ] `claude` → `/logout` → `/login` → `/status` 에 내 이메일이 보인다
- [ ] (필요하면) GitHub Fork 하고 `git remote -v` 가 내 아이디다
- [ ] `git push` 가 내 저장소로 올라간다
- [ ] `bash scripts/shorts doctor` 가 전부 `OK`
- [ ] `bash scripts/smoke_test_render.sh` 가 PASS
- [ ] `bash scripts/shorts-auto.sh` 로 한 편이 나온다
- [ ] 아들 계정의 Apify · Gemini 키를 폐기했다

## 안 되면

- **`claude: command not found`** — Claude Code가 안 깔렸다.
  `docs/설치-맥.md` 4번으로 간다.
- **`/login` 후에도 아들 계정** — 브라우저에 아들 계정이 로그인돼 있는 것이다.
  브라우저에서 claude.ai 로그아웃 후 다시 `/login`.
- **`git push` 가 403** — 아직 남의 저장소를 보고 있다. 2-2를 다시 한다.
- **그 외** — 터미널에 나온 글자를 그대로 복사해서 Claude에게 붙여넣는다.
  어디서 멈췄는지가 그 안에 다 있다.
