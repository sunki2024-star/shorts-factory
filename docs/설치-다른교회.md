# 우리 교회 설교 쇼츠 만들기 — 모든 교회용

> 명령어를 눌러 복사하며 따라가는 웹판: <https://claude.ai/code/artifact/ae195728-4e30-470e-905a-f210d6d55817>
> 인쇄용 PDF: `docs/pdf/우리교회-쇼츠-만들기.pdf`

유튜브에 올려 둔 설교에서 세로 쇼츠를 자동으로 뽑는 프로그램이다. 교회 채널
주소와 설교자 이름, 교회명만 넣으면 그 교회 것으로 돈다. **전부 무료고 API 키가
필요 없다.**

- 맥 또는 윈도우 · 여유 공간 20GB · 인터넷
- 비용 0원

## 무엇을 해 주는가 — 설교 한 편 → 쇼츠 3편

유튜브 예배 영상을 받아, 한국어로 받아쓰고, 쇼츠로 쓸 구간 세 개를 **전사본을
읽고** 고른 뒤, 세로로 잘라 자막을 입혀 MP4로 내놓는다. 사람이 하는 일은
마지막에 **골라서 올리는 것**뿐이다.

- 9:16 세로 · 1080×1920 · **1.5배속**
- 한국어 자막 **번인** — 유튜브 UI와 안 겹치게 배치
- 끝에 **엔드카드 4초** — 날짜 · 본문 · 제목 · 설교자 · 교회명
- 주일예배 실황에서는 **설교 구간 안에서만** 자른다. 찬양·기도·광고는 제외 —
  Content ID를 피하기 위해서다
- 새벽기도처럼 **정지 이미지에 음성만** 올린 영상도 된다. 이미지를 잘라내지 않고
  9:16에 맞춘다
- **업로드는 절대 자동으로 하지 않는다.** 렌더까지가 끝이다
- **설교자 음성을 합성하지 않는다.** 실제 하신 말씀만 자른다

# 1부 · 설치 (딱 한 번, 40~60분)

여기만 운영체제에 따라 갈린다. **본인 것만** 하면 된다.

## 맥에서 (0-1 ~ 0-4)

### 0-1. 터미널 열기

`command` + `스페이스` 를 누르고 **터미널** 이라고 친 뒤 `Enter`. 검은 창이
뜨고 `%` 로 끝나는 줄이 보인다. 여기에 명령을 붙여넣는다.

> 회색 상자 안의 것만 복사한다. 설명 문장은 같이 복사하지 않는다.
> 한 줄씩 붙여넣고 `Enter`.

### 0-2. 개발자 도구 (5~10분)

```bash
xcode-select --install
```

창이 뜨면 **설치**를 누른다. 이미 깔려 있으면
`command line tools are already installed` 라고 나오는데 그것도 정상이다.

```bash
git --version
```

버전이 나오면 됐다.

### 0-3. Homebrew (10~20분)

맥에 프로그램을 깔아 주는 도구다. 아래 한 줄이 전부다.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

맥 로그인 암호를 물으면 친다. **화면에 아무 글자도 안 나오는 것이 정상이다.**
다 치고 `Enter`. 중간에 한 번 더 `Enter` 를 누르라고 한다.

끝나면 **다음 두 줄을 반드시 실행한다.** 이걸 빼면 뒤에서
`brew: command not found` 가 난다.

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
```

```bash
eval "$(/opt/homebrew/bin/brew shellenv)"
```

```bash
brew --version
```

버전이 나오면 됐다.

### 0-4. Node.js (3~5분)

```bash
brew install node
```

```bash
node --version
```

`v22.x.x` 처럼 나오면 됐다. **여기까지가 맥에서만 하는 부분이다.**

## 윈도우에서 (0-1 ~ 0-4)

### 0-1. Git for Windows (5분)

<https://git-scm.com/download/win> 에서 받아 실행한다. 선택지가 많이 나오는데
**전부 기본값 그대로 `Next`** 면 된다.

딱 하나만 본다 — `Adjusting your PATH environment` 화면에서
**"Git from the command line and also from 3rd-party software"** 가 선택돼
있어야 한다. 그게 기본값이다.

설치가 끝나면 **시작 메뉴에서 `Git Bash` 를 찾아 연다.** 검은 창이 뜨고
`$` 로 끝나는 줄이 보인다. 앞으로 모든 작업을 여기서 한다 —
**`명령 프롬프트` 나 `PowerShell` 이 아니다.**

```
사용자@PC MINGW64 ~
$
```

붙여넣기는 `Ctrl` + `V` 또는 마우스 오른쪽 버튼 → Paste.

```bash
git --version
```

### 0-2. Python (5분)

<https://www.python.org/downloads/windows/> 에서 최신 3.x를 받는다.

**설치 첫 화면 맨 아래 `Add python.exe to PATH` 를 반드시 체크한다.**
이걸 놓치면 뒤가 전부 안 된다. 체크하고 `Install Now`.

Git Bash를 **닫고 새로 연 뒤**:

```bash
python --version
```

아무 반응이 없으면 PATH 체크를 놓친 것이다. 다시 설치하면서 그 칸을 체크한다.

### 0-3. Node.js LTS (5분)

<https://nodejs.org> 에서 **LTS** 라고 적힌 쪽을 받아 설치한다. 전부 기본값.

Git Bash를 **닫고 새로 연 뒤**:

```bash
node --version
```

### 0-4. 창을 새로 열기

Git Bash를 **완전히 닫고 다시 연다.** 방금 깐 것들이 이 창에 잡히게 하려면
필요하다. **여기까지가 윈도우에서만 하는 부분이다.**

**여기서부터는 맥·윈도우가 완전히 같다.** 명령이 하나의 형태
(`bash scripts/shorts …`)로 통일돼 있어서다.

```bash
npm install -g @anthropic-ai/claude-code
```

```bash
claude
```

브라우저가 열리면 Claude 계정으로 로그인하고 `/exit` 로 나온다.
Claude 구독이 있으면 추가 비용이 없다 — 쇼츠 구간을 고르는 데만 쓴다.

```bash
cd ~
```

```bash
git clone -b claude/shorts-creation-automation-0xaii8 https://github.com/Kairose-master/shorts-factory
```

```bash
cd ~/shorts-factory
```

```bash
bash scripts/setup_render_env.sh --with-whisper
```

20~40분 걸린다. 끝나면 `export` 로 시작하는 두 줄이 나온다. 맥은 `~/.zshrc`,
윈도우는 `~/.bashrc` 에 넣고 **터미널을 닫았다 새로 연다.**

# 2부 · 우리 교회로 맞추기 (딱 한 번, 1분)

세 가지만 넣으면 된다.

| | 무엇 |
|---|---|
| **채널 주소** | 유튜브에서 교회 채널에 들어가 주소창의 `@` 로 시작하는 주소 |
| **설교자** | 영상 **제목에 적히는 이름 그대로**. "홍길동 목사"면 `홍길동` 만 |
| **교회명** | 엔드카드에 찍힐 이름 |

```bash
bash scripts/shorts config --channel https://www.youtube.com/@내채널 --preacher 홍길동 --church "서울○○교회"
```

제대로 잡혔는지 본다:

```bash
bash scripts/shorts sermons
```

```
https://www.youtube.com/@내채널  ·  홍길동 새벽기도 757편 · 수요예배 30편 · 주일예배 185편

  2026-08-30  주일예배  69분  l3LbSLU39jU  2026-08-30 [삼하 22:1-8] …
  2026-08-28  새벽기도  43분  Y1ABPz8B7kw  2026-8-28[겔47:13-23]/새벽기도/…
```

> **아무것도 안 나오면 설교자 이름이 제목과 다르다.** 제목에 이름이 아예 없는
> 채널이면 `--preacher ""` 로 비워 두고 모든 영상을 대상으로 할 수 있다. 다만
> 그러면 어린이부·행사 영상까지 섞이니 결과를 꼭 확인한다.

> **영상 제목에 날짜와 성경 본문이 있으면 훨씬 좋다.**
> `2026-08-30 [삼하 22:1-8] 제목 / 홍길동 목사` 처럼. 날짜로 폴더 이름을,
> 본문과 제목으로 엔드카드를 자동으로 채운다. 없어도 돌아가지만 엔드카드를
> 손으로 채워야 한다.

확인:

```bash
bash scripts/shorts doctor
```

`subtitles` 줄이 **`OK` 여야 한다.** `MISS` 면 ffmpeg는 깔렸는데 자막을 입히는
부품(libass)이 빠진 것이고, 그대로 두면 마지막 렌더에서만
`No such filter: 'subtitles'` 로 죽는다. 맥이라면:

```bash
brew install ffmpeg-full
```

```bash
ffmpeg -filters | grep subtitles
```

한 줄이라도 나오면 통과다. 안 나오면 `brew link --overwrite ffmpeg-full`.
윈도우라면 `bash scripts/setup_render_env.sh` 를 다시 돌린다.

> **`brew reinstall ffmpeg` 는 소용없다.** 같은 것이 다시 깔린다. `-full` 이
> 붙은 쪽이 자막 부품을 갖고 있다.

마지막으로:

```bash
bash scripts/smoke_test_render.sh
```

`PASS` 가 나오면 준비 끝이다.

# 3부 · 만들기

**플랜 A — 알아서 골라줘.** 아직 안 만든 설교를 무작위로 하나 뽑아 끝까지 간다.
주일예배·수요예배·새벽기도가 골고루 뽑히도록 종류를 먼저 고른다.

```bash
bash scripts/shorts-auto.sh
```

**플랜 B — 이 설교로 해줘.** 주소를 큰따옴표로 감싼다.

```bash
bash scripts/shorts-url.sh "https://www.youtube.com/watch?v=..."
```

## 렌더 전에 화면 확인 · 1분

세로 화면은 가로 영상의 **3분의 1**만 쓴다. 설교자가 그 안에 들어왔는지
**굽기 전에** 사진으로 본다. 렌더는 10분 넘게 걸리지만 이건 1분이다.

```bash
bash scripts/shorts preview SUN-2026-08-30
```

```
preview/
├── clip-01.jpg           실제로 나올 세로 화면
└── clip-01-전체화면.jpg   원본 전체 + 노란 네모가 잘라낼 구간
```

파일 탐색기(Finder)가 열리면 두 장을 본다. `-전체화면` 쪽의 **노란 네모가 설교자를 감싸고
있으면** 그대로 렌더한다. 네모가 빈 강단이나 화면 끝을 잡고 있으면 아래
**화면이 이상하게 잘렸을 때**로 간다.

새벽기도처럼 정지 이미지에 음성만 있는 영상은 노란 네모 없이 **화면 전체**가
들어간다. 그게 정상이다.

## 얼마나 걸리나

```
1/4 내려받기    5~15분
2/4 한국어 전사  20~60분   ← 제일 오래 걸린다
3/4 구간 선별    2~5분
4/4 렌더        3~15분
```

- 터미널 창을 **닫으면 중단된다.** 그대로 둔다
- 컴퓨터가 잠들면 멈춘다. 절전을 꺼 두거나 가끔 마우스를 움직인다
- 중간에 끊겨도 **같은 명령을 다시 치면 이어서** 간다

## 결과

렌더가 끝나면 **파일 탐색기(Finder)가 저절로 열린다.**

```
SUN-2026-08-30/
├── renders/            ← MP4 3편. 여기서 확인한다
├── captions/           ← 자막이 틀리면 여기를 고친다
├── publish-package.md  ← 제목 · 훅 · 설명문 · 선정 근거
└── source/             ← 받아둔 원본 (지워도 된다)
```

창이 안 열렸으면 `bash scripts/shorts open SUN-2026-08-30`.

반대로 창이 자동으로 뜨는 게 거슬리면 `render` 뒤에 `--no-open` 을 붙이거나,
늘 안 뜨게 하려면 셸 설정에 `export SHORTS_NO_OPEN=1` 을 넣는다.

`publish-package.md` 의 제목과 설명문을 그대로 복사해 올리면 된다.
`⚠️` 가 붙은 클립은 올리기 전에 확인한다.

# 4부 · 고치기

## 자막 글자가 틀렸을 때

**한 단어가 계속 틀린다:**

```bash
bash scripts/shorts fix SUN-2026-08-30 혜성교회 예심교회 --remember
```

```bash
bash scripts/shorts render SUN-2026-08-30
```

`--remember` 를 붙이면 앞으로 만드는 모든 편에 자동 적용된다.

**문장을 직접 다듬는다:**

렌더가 끝나면 `captions` 폴더가 **저절로 만들어져 있다.** 따로 명령을 칠 필요가 없다.

```
captions/
├── clip-01.srt
├── clip-02.srt
├── clip-03.srt
└── 여기서 자막을 고칩니다.txt   ← 뭘 하면 되는지 적혀 있다
```

폴더를 바로 열려면:

```bash
bash scripts/shorts open SUN-2026-08-30 captions
```

> **`renders/subs/` 안의 srt 는 고쳐도 소용없다.** 그쪽은 렌더할 때마다 새로
> 만들어지는 결과물이다. 고칠 곳은 `captions/` 다.

메모장·텍스트편집기로 열어 **맨 아랫줄 글자만** 고친다. 시간 줄은 그대로 둔다.
워드·한글(HWP)은 파일을 망가뜨리니 쓰지 않는다.
**반드시 저장한다** (`command`/`Ctrl` + `S`).

```bash
bash scripts/shorts captions SUN-2026-08-30 --show
```

지금 파일에 뭐라고 적혀 있는지 디스크에서 그대로 읽어 준다. 저장이 됐는지,
렌더를 돌렸는지까지 알려준다.

```bash
bash scripts/shorts render SUN-2026-08-30 --only clip-01
```

`--only` 로 한 편만 다시 구우면 1~3분이면 끝난다.

## 화면이 이상하게 잘렸을 때

설교자가 한쪽으로 치우쳐 잘렸다면, 그 영상의 화면 배치가 평소와 달랐던 것이다.
예심교회 방송은 **해마다 배치가 바뀌었고** 강단 위치도 주일마다 달라진다.

> **설교자를 찾아서 가운데 놓는다.** 고정된 좌표를 쓰지 않는다. 1초 간격
> 프레임을 설교 구간 여덟 지점에서 비교해 **움직이는 사람**을 찾고 그를 가운데 둔다 —
> 배경·자막·그래픽은 움직이지 않으니 구분된다. 새벽기도처럼 **정지 이미지에
> 음성만** 있는 영상은 사람이 없으므로 자르지 않고 화면 전체를 9:16에 맞춘다.

먼저 `preview` 로 지금 어디를 잡고 있는지 사진으로 확인한다. 렌더를 다시
돌리지 않아도 된다.

```bash
bash scripts/shorts preview SUN-2026-08-30
```

그래도 어긋났으면 `clips.json` 의 `crop` 을 직접 준다. 숫자는 원본 영상 기준
픽셀이다.

```
"crop": { "x": 126, "y": 108, "h": 252 }

   x  왼쪽에서 몇 픽셀부터
   y  위에서 몇 픽셀부터
   h  높이 (폭은 9:16에 맞춰 자동)
```

```bash
bash scripts/shorts render SUN-2026-08-30
```

간단히 `"crop": "center"` · `"left"` · `"right"` 로 써도 되고, 정지 이미지처럼
**자르지 않고 통째로** 넣으려면 `"crop": "fit"` 이다.

## 자막이 영상과 안 맞을 때

글자는 맞는데 **나오는 때가 어긋나는** 경우다. 말이 끝난 뒤에 자막이 뜨거나
미리 떠 버린다. 글자가 틀린 것과는 원인이 다르다 — 그 자막 파일이 **다른
구간에 맞춰 만들어진 것**이고, 구간을 바꾼 뒤 옛 자막이 남아 있을 때 생긴다.

확인은 한 줄이면 된다. 전사본과 대조해 몇 초 어긋났는지 말해 준다.

```bash
bash scripts/shorts captions SUN-2026-08-30 --show
```

```
  clip-01
    ✗ 25초 늦게 나온다 — 이 자막은 다른 구간에 맞춰진 파일이다
  clip-02
    영상과 맞는다 (어긋남 +0.1초, 일치도 96%)
```

어긋났다고 나오면 그 자막을 지우고 **지금 구간에 맞춰** 다시 꺼낸다.

```bash
rm office/production/SUN-2026-08-30/captions/clip-01.srt
```

```bash
bash scripts/shorts captions SUN-2026-08-30
```

```bash
bash scripts/shorts render SUN-2026-08-30 --only clip-01
```

고쳐 둔 글자가 아까우면 `.이전` 파일에서 옮겨 온다 — 지우지 않고 남겨 둔다.

## 그 밖에

| 고치고 싶은 것 | 방법 |
|---|---|
| 구간의 초를 조정 | `clips.json` 의 start / end 를 고치고 render |
| 다른 구간으로 다시 | `shorts select <id> --count 3` → render |
| 설교 구간을 잘못 잡음 | `transcript.json` 지우고 `transcribe <id> --sermon-window 0:45:00 1:20:00` |
| 화면이 치우쳐 잘림 | `clips.json` 의 `crop` 을 직접 준다 — 위 참조 |
| 엔드카드 내용 | `end-card.json` 을 고치고 render |
| 엔드카드 빼기 | `render <id> --no-end-card` |
| 제목 크기 | `TITLE_SIZE=110` 을 앞에 붙여 render (기본 92) |
| 폴더 창 안 뜨게 | `render` 뒤에 `--no-open`. 늘 그러려면 `SHORTS_NO_OPEN=1` |
| 용량이 찰 때 | `source/` 폴더만 지운다 — 아래 참조 |

## 용량이 찰 때 — 원본만 지운다

한 편이 **300MB쯤** 되는데 그 **90% 이상이 받아둔 원본 영상**이다.
완성된 MP4와 자막은 다 합쳐도 20MB 남짓이다.

| 폴더 | 크기 | 지워도 되나 |
|---|---|---|
| `source/` | 약 275MB | **지운다** — 다시 받을 수 있다 |
| `renders/` | 약 21MB | 남긴다 — 완성된 MP4 |
| `captions/` 등 나머지 | 0.1MB | 남긴다 — 자막 · 전사본 · 선정 근거 |

**파일 탐색기(Finder)에서 `source` 폴더만 휴지통에 넣으면 된다.** 폴더 자체는 남겨 둔다 —
어떤 설교를 만들었는지 남고, 다시 뽑히지도 않는다.

```
SUN-2026-08-30/
├── renders/            남긴다
├── captions/           남긴다
├── source/             ← 이것만 지운다
├── transcript.json     남긴다
├── clips.json          남긴다
└── meta.json           남긴다 — 어떤 영상이었는지
```

> **폴더를 통째로 지워도 다시 뽑히지 않는다.** 만든 기록은 폴더 밖
> `office/produced.json` 에도 따로 남는다. 실수로 폴더 안을 다 비워도, 폴더째
> 지워도 그 설교는 목록에서 계속 빠진다. 실제로 지워 보고 확인한 동작이다.

터미널이 편하면:

```bash
rm -rf office/production/SUN-2026-08-30/source
```

원본이 다시 필요하면 같은 주소로 받으면 된다. 기록이 있어도 **주소를 직접 주면
받는다** — 막지 않는다. 전사본과 자막이 남아 있으면 전사도 다시 하지 않는다.

# 막힐 때

| 화면에 나온 것 | 뜻 | 할 것 |
|---|---|---|
| `command not found: python` | 맥은 python3 다 | `bash scripts/shorts …` 형태로 친다 |
| `python: command not found` | 윈도우 PATH 체크 안 함 | Python 재설치, `Add python.exe to PATH` |
| `URL이 아니다: '#'` | 설명까지 복사됨 | 회색 상자 안만 복사 |
| `전사할 수단이 없다` | whisper 미설치 | `setup_render_env.sh --with-whisper` |
| `No such filter: 'subtitles'` | 자막 부품 없는 ffmpeg | 맥은 `brew install ffmpeg-full` |
| `아무것도 못 찾았다` | 설교자 이름이 제목과 다름 | `shorts sermons` 확인 후 `config` 다시 |
| `자막을 고쳤는데 그대로` | 저장 안 됨 / 다른 폴더 | `captions … --show` 로 확인 |
| 20분간 아무것도 안 나옴 | 전사 중 | 정상. 기다린다 |

그래도 안 되면 **터미널 글자를 그대로 복사해서** Claude에게 붙여넣는다.

# 교회에서 쓰기 전에 — 지켜야 할 선

- **업로드는 사람이 한다.** 어느 단계에도 자동 업로드가 없다
- **찬양 구간은 피한다.** CCLI는 예배 사용 범위이지 유튜브 배포 범위가 아니다.
  찬양이 깔린 구간에는 경고가 붙는다
- **회중석이 잡힌 화면은 확인한다.** 성도 얼굴이 나오면 크롭하거나 버린다
- **설교자 음성을 합성하지 않는다.** 실제 하신 말씀만 자른다
- 설교 구간 밖은 잘려 나가고, 15초 미만은 버려지며, 왜 그 구간인지 근거가 없으면
  렌더가 거부된다 — 저작권 방어선은 모델의 판단이 아니라 파이프라인 구조에 있다
