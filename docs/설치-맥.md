# 맥에서 처음부터 — 쇼츠 만들기 전체 순서

> 명령어를 눌러 복사하며 따라가는 웹판: <https://claude.ai/code/artifact/9c82f121-5ef0-434d-944d-d18df44b2a73>
> 인쇄용 PDF: `docs/pdf/쇼츠-만들기-맥.pdf`

새 맥에 아무것도 없는 상태에서 시작해, 쇼츠 3편이 나오고, 자막까지 고치는
데까지. **1부는 딱 한 번만**, 2부부터는 만들 때마다 반복한다.

전부 무료다. API 키가 하나도 필요 없다.

**이 문서 하나면 된다.** 설치 → 유튜브에서 설교 가져오기 → 쇼츠 3편 → 자막 수정까지.

| | 무엇을 | 언제 |
|---|---|---|
| **1부** | 도구 설치 · 확인 | 딱 한 번 |
| **2부** | 영상 고르기 → 전사 → 구간 선별 → 자막·엔드카드 렌더 | 만들 때마다 |
| **3부** | 자막 글자 고치고 다시 렌더 · 구간 조정 · 엔드카드 수정 | 마음에 안 들 때 |


- 맥 (인텔 / M1 / M2 / M3 다 됨)
- 여유 공간 **20GB** — 전사 모델 3GB, 예배 영상 한 편 1GB 정도
- 인터넷

# 1부 · 설치 (한 번만, 40분~1시간)

## 1. 터미널 열기

`command` + `스페이스` → `터미널` → `Enter`.

검은 창이 뜨고 `%` 로 끝나는 줄이 보인다. 여기에 명령을 친다.
아래 명령들은 **한 줄씩** 복사해 붙여넣고 `Enter`.

> 회색 상자 안의 것만 복사한다. 설명 문장은 같이 복사하지 않는다.

## 2. 개발자 도구

```bash
xcode-select --install
```

창이 뜨면 **설치**를 누른다. 5~10분. 이미 깔려 있으면
`command line tools are already installed` 라고 나오는데 정상이다.

## 3. Homebrew

맥에 프로그램을 깔아 주는 도구다.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

맥 로그인 암호를 물으면 친다. **화면에 아무 글자도 안 나오는 게 정상이다.**
다 치고 `Enter`.

끝나면 화면 마지막에 `eval "$(/opt/homebrew/bin/brew shellenv)"` 같은 줄이
나온다. **그 줄을 그대로 복사해서 한 번 더 실행한다.** 그리고:

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
```

확인:

```bash
brew --version
```

버전이 나오면 됐다.

## 4. Node.js와 Claude Code

```bash
brew install node
```

```bash
npm install -g @anthropic-ai/claude-code
```

```bash
claude
```

처음 실행하면 브라우저가 열리고 로그인하라고 한다. Claude 계정으로 로그인한다.
로그인이 끝나면 `/exit` 를 쳐서 나온다.

> **Claude 구독이 있으면 추가 비용이 없다.** 쇼츠 구간을 고르는 데만 쓴다.

## 5. 프로그램 받기

```bash
cd ~
```

```bash
git clone -b claude/shorts-creation-automation-0xaii8 https://github.com/sunki2024-star/shorts-factory
```

```bash
cd ~/shorts-factory
```

## 6. 도구 설치

```bash
bash scripts/setup_render_env.sh --with-whisper
```

**20~40분 걸린다.** 영상 편집기(ffmpeg), 유튜브 다운로더(yt-dlp), 한국어 음성
인식 모델(3GB)을 받는다. 중간에 여러 줄이 지나가는데 그냥 두면 된다.

끝나면 마지막에 `export` 로 시작하는 **두 줄**이 나온다. 그 두 줄을 넣어야
한다:

```bash
echo 'export PATH="$HOME/whisper.cpp/build/bin:$PATH"' >> ~/.zshrc
```

```bash
echo 'export WHISPER_MODEL="$HOME/whisper.cpp/models/ggml-large-v3.bin"' >> ~/.zshrc
```

**터미널을 완전히 닫고 새로 연다.** (`command` + `Q` → 다시 열기)

### 6-1. 자막이 되는 ffmpeg인지 확인 (맥만, 2분)

**이 확인을 건너뛰면 렌더 단계에서 막힌다.** Homebrew의 기본 `ffmpeg` 는
자막을 입히는 부품(libass)을 **빼고** 오는 경우가 있다. 그러면 다른 건 다
정상인데 마지막 렌더에서만 `No such filter: 'subtitles'` 로 죽는다.

```bash
ffmpeg -filters | grep subtitles
```

`subtitles` 가 들어간 줄이 **하나라도 나오면 통과다.** 다음으로 넘어간다.

아무것도 안 나오면 자막이 되는 쪽을 깐다:

```bash
brew install ffmpeg-full
```

15~20분 걸린다. 끝나면 다시 확인한다:

```bash
ffmpeg -filters | grep subtitles
```

그래도 안 나오면 옛 ffmpeg에 링크가 걸려 있는 것이다:

```bash
brew link --overwrite ffmpeg-full
```

> **`brew reinstall ffmpeg` 는 소용없다.** 같은 것이 다시 깔린다. `-full` 이
> 붙은 쪽을 깔아야 한다.

## 7. 확인

```bash
cd ~/shorts-factory
```

```bash
bash scripts/shorts doctor
```

이렇게 나와야 한다:

```
  OK    ffmpeg       /opt/homebrew/bin/ffmpeg
  OK    yt-dlp       /opt/homebrew/bin/yt-dlp
  OK    whisper      /Users/…/whisper.cpp/build/bin/whisper-cli
  OK    subtitles    자막을 입힐 수 있다 (libass)
  OK    claude       /opt/homebrew/bin/claude
  OK    korean font  2 file(s) in …/assets/fonts
  OK    whisper model /Users/…/ggml-large-v3.bin
  n/a   GEMINI_API_KEY not needed — whisper handles transcription
```

`subtitles` 줄이 **`MISS` 면 렌더가 안 된다.** ffmpeg는 깔렸는데 자막 부품이
빠진 경우다. 아래 6-1번으로 간다.

`GEMINI_API_KEY` 가 `n/a` 인 것은 **정상이다.** whisper가 있으면 안 쓴다.

마지막으로 실제 렌더가 되는지 본다. 인터넷 없이 30초, 무료:

```bash
bash scripts/smoke_test_render.sh
```

`PASS` 가 나오면 설치 끝이다.

# 2부 · 쇼츠 만들기 (만들 때마다)

## 매번 하는 두 줄

> **명령은 전부 `bash scripts/shorts …` 로 시작한다.** 맥이든 윈도우든 똑같다.
> 파이썬을 `python` 으로 부를지 `python3` 으로 부를지는 이 스크립트가 알아서
> 고른다 — 그 차이 때문에 한쪽 명령을 다른 쪽에 붙여넣는 사고가 나서 없앴다.


```bash
cd ~/shorts-factory
```

```bash
git pull
```

## 플랜은 둘, 하나만 고른다

| | 플랜 A — 알아서 | 플랜 B — 내가 지정 |
|---|---|---|
| 영상 | 채널에서 무작위로 뽑음 | 내가 주소를 넣음 |
| 언제 | 아무거나 하나 | 이번 주 설교를 꼭 |

### 플랜 A

```bash
bash scripts/shorts-auto.sh
```

아직 안 만든 주일예배 중 하나를 뽑아 렌더까지 간다. 끝.

뭐가 남았는지 먼저 보려면 (무료):

```bash
bash scripts/shorts sermons
```

### 플랜 B

유튜브에서 `방배동 예심교회` → **실시간 스트림** 탭 → 설교를 열고 주소 복사.
주일예배는 "동영상" 탭이 아니라 실시간 스트림 탭에 있다.

```bash
bash scripts/shorts-url.sh "https://www.youtube.com/watch?v=여기에붙여넣기"
```

주소를 **큰따옴표로 감싼다.** 유튜브 주소의 `?` 와 `&` 는 따옴표가 없으면
셸이 먼저 먹어버린다.

## 렌더 전에 화면 확인 · 1분

세로 화면은 가로 영상의 **3분의 1**만 쓴다. 설교자가 그 안에 들어왔는지
**굽기 전에** 사진으로 본다. 렌더는 10분 넘게 걸리지만 이건 1분이다.

```bash
bash scripts/shorts preview SUN-2026-08-09
```

```
preview/
├── clip-01.jpg           실제로 나올 세로 화면
└── clip-01-전체화면.jpg   원본 전체 + 노란 네모가 잘라낼 구간
```

Finder가 열리면 두 장을 본다. `-전체화면` 쪽의 **노란 네모가 설교자를 감싸고
있으면** 그대로 렌더한다. 네모가 빈 강단이나 화면 끝을 잡고 있으면 아래
**화면이 이상하게 잘렸을 때**로 간다.

새벽기도처럼 정지 이미지에 음성만 있는 영상은 노란 네모 없이 **화면 전체**가
들어간다. 그게 정상이다.

## 기다리기

```
━━ 1/4 원본 내려받기   5~15분
━━ 2/4 한국어 전사    20~40분   ← 제일 오래 걸린다
━━ 3/4 구간 선별      2~5분
━━ 4/4 렌더          3~10분
```

**전체 40분~1시간.** 예배가 100분인 편도 있어 길이에 따라 늘어난다.
2단계에서 몇 분간 글자가 안 나와도 정상이다. 멈춘 게 아니다.

- 터미널 창을 **닫지 말 것.** 닫으면 중단된다.
- 맥이 잠들면 멈춘다. 시스템 설정 → 잠금 화면 → 디스플레이 끄기를 `안 함` 으로
- 중간에 끊겨도 **같은 명령을 다시 치면 이어서** 간다. 다시 받지 않는다.

## 결과 보기

렌더가 끝나면 **Finder가 저절로 열린다.** 폴더 안이 이렇게 되어 있다.

```
SUN-2026-08-09/
├── renders/            ← MP4 3편. 여기서 확인한다
├── captions/           ← 자막이 틀리면 여기를 고친다
├── publish-package.md  ← 제목 · 설명문 · 선정 근거
└── source/             ← 받아둔 원본 (지워도 된다)
```

`renders` 의 MP4 3개를 더블클릭해서 본다. 자막이 틀렸으면 한 단계 올라와
`captions` 로 들어가면 된다 — **이미 만들어져 있다.**

창이 안 열렸으면:

```bash
bash scripts/shorts open SUN-2026-08-09
```

반대로 **창이 자동으로 뜨는 게 거슬리면** 명령 뒤에 `--no-open` 을 붙인다:

```bash
bash scripts/shorts render SUN-2026-08-09 --no-open
```

늘 안 뜨게 하려면 한 번만:

```bash
echo 'export SHORTS_NO_OPEN=1' >> ~/.zshrc
```

`publish-package.md` 에 각 클립의 **제목 / 훅 / 설명문 / 왜 이 구간인지** 가
정리돼 있다. 유튜브에 올릴 때 그대로 복사해 쓰면 된다.

## 업로드

**자동 업로드는 없다.** 마음에 드는 편을 골라 직접 올린다.
`⚠️` 가 붙은 클립은 올리기 전에 꼭 확인한다 — 찬양이 깔렸거나 회중석 얼굴이
잡힌 경우다.

# 3부 · 고치기

## 자막 글자가 틀렸을 때

**이게 제일 흔하다.** 음성 인식이 사람 이름이나 교회 이름을 잘못 듣는다.

### 한 단어가 계속 틀리는 경우

```bash
bash scripts/shorts fix SUN-2026-08-09 혜성교회 예심교회 --remember
```

```bash
bash scripts/shorts render SUN-2026-08-09
```

전사본과 자막에서 그 말을 **한 번에** 바꾼다. 어디를 고쳤는지 시각과 함께
보여준다.

`--remember` 를 붙이면 **앞으로 만드는 모든 편에 자동으로 적용된다.**
교회 이름처럼 매번 틀리는 말은 한 번만 등록하면 된다.

### 문장을 직접 다듬고 싶은 경우

세 단계다. 1번은 한 번만, 2~3번은 고칠 때마다 반복한다.

```
captions  →  텍스트편집기(TextEdit)  →  render
자막 꺼내기    글자 고치기      다시 굽기
```

**1 · 자막 파일은 이미 있다**

렌더가 끝나면 `captions` 폴더가 **저절로 만들어져 있다.** 따로 명령을 칠 필요가 없다.

```
captions/
├── clip-01.srt
├── clip-02.srt
├── clip-03.srt
└── 여기서 자막을 고칩니다.txt   ← 뭘 하면 되는지 적혀 있다
```

> **`renders/subs/` 안의 srt 는 고쳐도 소용없다.** 이름이 같아서 헷갈리는데,
> 그쪽은 렌더할 때마다 새로 만들어지는 결과물이다. 고칠 곳은 `captions/` 다.

폴더가 없으면 (옛날에 만든 편이라면) 이걸로 꺼낸다:

```bash
bash scripts/shorts captions SUN-2026-08-09
```

**2 · srt 파일 열어서 고치기**

`.srt` 는 **글자만 든 파일**이다. 메모장 종류면 다 열린다.

- **쓴다** — 텍스트편집기(TextEdit). 컴퓨터에 기본으로 있다. VS Code 같은 편집기가 있으면 그것도 좋다
- **안 쓴다** — 워드 · 한글(HWP) · 엑셀. 열리기는 하지만 저장할 때 자기 형식으로
  바꿔 버려 파일이 망가진다

**터미널에서 바로 열기**

```bash
open -e office/production/SUN-2026-08-09/captions/clip-01.srt
```

**Finder에서 열기**

가장 쉬운 길 — 터미널에서 한 줄이면 그 폴더가 Finder로 열린다:

```bash
bash scripts/shorts open SUN-2026-08-09 captions
```

또는 직접 찾아가려면:

Finder 창에서 `command + shift + G` 를 누르면 주소 칸이 뜬다. 여기에 붙여넣고 엔터:

```
~/shorts-factory/office/production/SUN-2026-08-09/captions
```

폴더가 열리면 `clip-01.srt` 를 오른쪽 버튼 클릭 → **다음으로 열기** → **텍스트편집기**.

더블클릭하면 macOS가 "악성 코드가 없음을 확인할 수 없습니다"라는 경고를 띄운다.
오른쪽 버튼으로 열면 안 뜬다.

**매번 오른쪽 클릭이 귀찮으면** — 파일을 한 번 클릭하고 `command` + `I` → **다음으로 열기**를 텍스트편집기로
바꾸고 **모두 변경…**. 한 번만 해 두면 `.srt` 는 더블클릭으로
바로 열린다.

**고치기**

파일은 이렇게 생겼다:

```
1
00:00:00,000 --> 00:00:03,400
근데 그 강사님이 생각을 해 보니까
```

**숫자와 `-->` 줄은 건드리지 않는다. 맨 아랫줄 글자만 고친다.**
시간을 바꾸면 자막이 말과 어긋난다. 실수로 망가뜨리면 렌더가 멈추고 이유를 말해 준다.

**고쳤으면 반드시 `command + S` 로 저장한다.** 텍스트편집기는 저장하기 전까지 고친 내용을
**창에만** 들고 있다. 저장을 안 하고 렌더하면 자막이 그대로다 — 가장 흔한 사고다.
저장되면 창 제목 옆의 점(●)이 사라진다. 그게 저장됐다는 표시다.

저장이 됐는지 확인하려면 — 지금 파일에 뭐라고 적혀 있는지 그대로 읽어 준다:

```bash
bash scripts/shorts captions SUN-2026-08-09 --show
```

렌더할 때도 수정본을 쓰면 첫 줄을 찍어 준다. 그 줄이 내가 고친 대로면 들어간 것이다.

**3 · 다시 렌더**

```bash
bash scripts/shorts render SUN-2026-08-09
```

`captions/` 에 파일이 있으면 렌더가 **그것을 쓴다.** 전사본은 쳐다보지도 않는다.
다시 전사해도 고친 자막은 그대로 남는다. 다만 **구간(시작·끝 시각)을 바꾸면**
자막 시간이 안 맞게 되므로 새 구간에 맞춰 다시 만들고, 고쳤던 파일은
`clip-01.srt.이전` 으로 남긴다 — 글자만 옮겨 오면 된다.

한 편만 다시 만들려면 — 3편 전부 다시 구울 필요가 없다:

```bash
bash scripts/shorts render SUN-2026-08-09 --only clip-02
```

다운로드와 전사는 건너뛰고 굽기만 하므로 **클립 하나에 1~3분**이다.

고치기 전으로 되돌리고 싶으면 그 srt를 지우고 `captions` 를 다시 돌린다.

## 엔드카드 글자가 틀렸을 때

카드에 나오는 날짜·본문·제목·설교자·교회명도 자막처럼 파일 하나 고치고
다시 렌더하면 된다.

```bash
open -e office/production/SUN-2026-08-09/end-card.json
```

파일은 이렇게 생겼다:

```json
{
  "date": "2026년 8월 9일 주일예배",
  "scripture": "사무엘하 19:31-39",
  "title": "나이 들면 바르실래처럼",
  "preacher": "설교 · 장선기 목사",
  "church": "방배동 예심교회",
  "handle": "youtube.com/@yeshim1126"
}
```

고치고 싶은 줄만 따옴표 안의 글자를 바꾼다. `title` 을 `""` 처럼 비워 두면
그 줄이 카드에서 통째로 빠진다 — 설교 제목 없이 본문만 나오게 하고 싶을 때
쓴다.

> 2026년 새벽기도처럼 원본에 제목이 없으면 이 파일이 자동으로 만들어질 때
> `title` 이 이미 **"본문 책 이름 + 강해"** 로 채워져 있다 — 시편이면
> `시편 강해`, 에스겔이면 `에스겔 강해`. 그것도 마음에 안 들면 여기서 바꾸거나
> 비워 두면 된다.

**`command + S` 로 저장한 뒤 다시 렌더한다.** `end-card.json` 이 이미 있으면
새로 만들지 않고 고친 그대로 쓴다.

```bash
bash scripts/shorts render SUN-2026-08-09
```

한 편만 다시 만들려면 3편 전부 다시 구울 필요 없다:

```bash
bash scripts/shorts render SUN-2026-08-09 --only clip-02
```

카드를 통째로 빼고 싶거나, 다섯 항목이 어디서 자동으로 채워지는지는 뒤쪽
"엔드카드 — 자동으로 붙는다" 절을 본다.

## 자막이 영상과 안 맞을 때

글자는 맞는데 **나오는 때가 어긋나는** 경우다. 말이 끝난 뒤에 자막이 뜨거나
미리 떠 버린다. 글자가 틀린 것과는 원인이 다르다 — 그 자막 파일이 **다른
구간에 맞춰 만들어진 것**이고, 구간을 바꾼 뒤 옛 자막이 남아 있을 때 생긴다.

확인은 한 줄이면 된다. 전사본과 대조해 몇 초 어긋났는지 말해 준다.

```bash
bash scripts/shorts captions SUN-2026-08-09 --show
```

```
  clip-01
    ✗ 25초 늦게 나온다 — 이 자막은 다른 구간에 맞춰진 파일이다
  clip-02
    영상과 맞는다 (어긋남 +0.1초, 일치도 96%)
```

어긋났다고 나오면 그 자막을 지우고 **지금 구간에 맞춰** 다시 꺼낸다.

```bash
rm office/production/SUN-2026-08-09/captions/clip-01.srt
```

```bash
bash scripts/shorts captions SUN-2026-08-09
```

```bash
bash scripts/shorts render SUN-2026-08-09 --only clip-01
```

고쳐 둔 글자가 아까우면 `.이전` 파일에서 옮겨 온다 — 지우지 않고 남겨 둔다.

## 구간이 마음에 안 들 때

`clips.json` 의 `start` / `end` 초만 고치고 렌더만 다시 한다:

```bash
open -e office/production/SUN-2026-08-09/clips.json
```

```bash
bash scripts/shorts render SUN-2026-08-09
```

다른 구간으로 아예 다시 골라달라고 하려면:

```bash
bash scripts/shorts select SUN-2026-08-09 --count 3
```

```bash
bash scripts/shorts render SUN-2026-08-09
```

## 설교 구간을 잘못 잡았을 때

찬양이나 광고가 클립에 들어갔다면 설교 시작·끝 시각을 직접 준다.
전사부터 다시 하므로 시간이 걸린다:

```bash
rm office/production/SUN-2026-08-09/transcript.json
```

```bash
bash scripts/shorts transcribe SUN-2026-08-09 --sermon-window 0:45:00 1:20:00
```

## 설교 제목 크기

화면 위쪽 제목은 기본 **92** 다. 더 크게 하려면 한 번만 붙여서 렌더한다:

```bash
TITLE_SIZE=110 bash scripts/shorts render SUN-2026-08-09
```

늘 크게 하고 싶으면 `~/.zshrc`에 넣는다:

```bash
echo 'export TITLE_SIZE=110' >> ~/.zshrc
```

줄바꿈은 크기에 맞춰 자동으로 조정된다 — 92는 한 줄 10자, 110은 8자다.
크게 할수록 줄 수가 늘어 화면을 많이 먹으니 110 위로는 권하지 않는다.

편별로 다르게 하려면 `clips.json` 의 그 클립에 `"title_size": 110` 을 넣는다.

## 화면이 이상하게 잘렸을 때

설교자가 한쪽으로 치우쳐 잘렸다면, 그 영상의 화면 배치가 평소와 달랐던 것이다.
예심교회 방송은 **해마다 배치가 바뀌었고** 강단 위치도 주일마다 달라진다.

> **설교자를 찾아서 가운데 놓는다.** 고정된 좌표를 쓰지 않는다. 1초 간격
> 프레임을 설교 구간 여덟 지점에서 비교해 **움직이는 사람**을 찾고 그를 가운데 둔다 —
> 배경·자막·그래픽은 움직이지 않으니 구분된다. 새벽기도처럼 **정지 이미지에
> 음성만** 있는 영상은 사람이 없으므로 자르지 않고 화면 전체를 9:16에 맞춘다.

먼저 `preview` 로 지금 어디를 잡고 있는지 사진으로 확인한다. 렌더를 다시
돌리지 않아도 된다.

```bash
bash scripts/shorts preview SUN-2026-08-09
```

그래도 어긋났으면 `clips.json` 의 `crop` 을 직접 준다. 숫자는 원본 영상 기준
픽셀이다.

```
"crop": { "x": 126, "y": 108, "h": 252 }

   x  왼쪽에서 몇 픽셀부터
   y  위에서 몇 픽셀부터
   h  높이 (폭은 9:16에 맞춰 자동)
```

```bash
bash scripts/shorts render SUN-2026-08-09
```

간단히 `"crop": "center"` · `"left"` · `"right"` 로 써도 되고, 정지 이미지처럼
**자르지 않고 통째로** 넣으려면 `"crop": "fit"` 이다.

## 엔드카드 — 자동으로 붙는다

**따로 할 일이 없다.** 본편이 끝나면 4초짜리 카드가 저절로 붙는다.

```
        2024년 6월 23일 주일예배      ← 언제 드린 예배인지
           신명기 12:1-8            ← 설교 본문
     택하신 곳으로 나아가야 하는 이유    ← 설교 제목
         설교 · 장선기 목사           ← 설교자
          방배동 예심교회             ← 교회명
       youtube.com/@yeshim1126
```

유튜브 영상 제목에 다섯 가지가 전부 들어 있어서 거기서 뽑는다. 쇼츠는 채널을
떠나 혼자 돌아다니기 때문에, 이걸 보고 유튜브에 검색하면 원래 설교 영상이 나온다.

- 본문은 **풀어서** 쓴다 — `삼하` → `사무엘하`. 줄임말로는 검색이 안 된다
- 날짜는 제목이 아니라 **폴더 이름**에서 가져온다. 채널 제목의 날짜가 틀린 적이
  있어서다 (2026-07-14는 화요일, 실제로는 07-12 주일예배였다)

### 내용을 고치고 싶으면

```bash
open -e office/production/SUN-2026-08-09/end-card.json
```

```bash
bash scripts/shorts render SUN-2026-08-09
```

파일이 이미 있으면 다시 만들지 않으므로 고친 내용이 유지된다.

### 카드를 빼고 싶으면

```bash
bash scripts/shorts render SUN-2026-08-09 --no-end-card
```

## 용량이 찰 때 — 원본만 지운다

한 편이 **300MB쯤** 되는데 그 **90% 이상이 받아둔 원본 영상**이다.
완성된 MP4와 자막은 다 합쳐도 20MB 남짓이다.

| 폴더 | 크기 | 지워도 되나 |
|---|---|---|
| `source/` | 약 275MB | **지운다** — 다시 받을 수 있다 |
| `renders/` | 약 21MB | 남긴다 — 완성된 MP4 |
| `captions/` 등 나머지 | 0.1MB | 남긴다 — 자막 · 전사본 · 선정 근거 |

**Finder에서 `source` 폴더만 휴지통에 넣으면 된다.** 폴더 자체는 남겨 둔다 —
어떤 설교를 만들었는지 남고, 다시 뽑히지도 않는다.

```
SUN-2026-08-09/
├── renders/            남긴다
├── captions/           남긴다
├── source/             ← 이것만 지운다
├── transcript.json     남긴다
├── clips.json          남긴다
└── meta.json           남긴다 — 어떤 영상이었는지
```

> **폴더를 통째로 지워도 다시 뽑히지 않는다.** 만든 기록은 폴더 밖
> `office/produced.json` 에도 따로 남는다. 실수로 폴더 안을 다 비워도, 폴더째
> 지워도 그 설교는 목록에서 계속 빠진다. 실제로 지워 보고 확인한 동작이다.

터미널이 편하면:

```bash
rm -rf office/production/SUN-2026-08-09/source
```

원본이 다시 필요하면 같은 주소로 받으면 된다. 기록이 있어도 **주소를 직접 주면
받는다** — 막지 않는다. 전사본과 자막이 남아 있으면 전사도 다시 하지 않는다.

# 만들어지는 것의 규칙

- 9:16 세로, 1080×1920, **1.5배속**
- 자막 **노란색**, 유튜브 UI(`@yeshim1126`)와 안 겹치게 올려 둠
- 끝에 **엔드카드 4초** — 날짜 · 본문 · 제목 · 설교자 · 교회명
- 구간은 **설교 안에서만** 자른다. 찬양·기도·광고는 애초에 제외
- 목사님 음성은 **실제 하신 말씀 그대로**. 합성하지 않는다
- 15초 미만은 버린다. 근거가 없으면 렌더를 거부한다
- **업로드는 사람이 한다.** 렌더가 마지막 단계다
- 렌더가 끝나면 폴더 창이 저절로 열린다 — 싫으면 `--no-open`
